# HealthyBites

Healthy recipe website. Built with Lovable.

## Stack
- TanStack Start (React 19)
- Vite 8
- Tailwind CSS 4
- shadcn/ui

## Pages
- `/` — Home
- `/recipes/healthy-low-carb-vegetarian` — Recipe page

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
